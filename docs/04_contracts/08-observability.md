# Observability Contract

The canonical observability contract for this project is:

[OpenObserve Integration Contract](openobserve.md)

It defines the OpenObserve deployment, OTLP transport, streams, structured
logging, metrics, tracing, alerts, security, retention, degradation behavior,
acceptance proof, and evidence boundary.

This compatibility pointer is retained because existing requirements and
implementation documents reference this path. Do not add new observability
requirements here. Update `openobserve.md` instead.
