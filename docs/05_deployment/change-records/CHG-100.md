## Change

1. **Twin smoke (default).** Step-7 smoke now runs against
   `<prefix>smoke_twin_<table>` — created from the same descriptor
   (`DdlText.toDescriptor(ddl)`), exercised, and dropped in `finally`.
   Real tables never receive fixture rows. `--allow-live-smoke` (env
   `DDL_APPLY_ALLOW_LIVE_SMOKE=1`) restores the old live-table smoke with a
   loud WARNING — debug/evidence escape hatch only (LOG fixture rows are
   undeletable).
2. **Sweep.** `--sweep` (no manifest/catalog preconditions): scan live
   tables for rows whose every field equals `defaultValue(type, i)` (the
   exact pre-CHG-100 generator) — `--sweep-table <name>` scopes, default
   all live tables. `--sweep-fix-kv` deletes KV fixtures
   (`UpsertWriter.delete` full-arity row, `flush()` in finally — not
   AutoCloseable). LOG fixtures are undeletable → reported, exit 3.
   Exit 0 = no fixtures remain or all deleted. Launcher:
   `DDL_APPLY_SWEEP=1 [DDL_APPLY_SWEEP_FIX_KV=1] [DDL_APPLY_SWEEP_TABLES=a,b]`.
3. **`Options.parse`** no longer requires `--ddl-dir` for sweep mode
   (sweep ignores it functionally; parses to a null Path safely).
