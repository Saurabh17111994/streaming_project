# CHG-101 — stale-image guard: no compose `build:` image older than its source

2026-08-24 the gateway+bridge containers still ran the **2026-08-20** images
while their source had changed (CHG-092 execution flag, TOTP-only auth): the
stale gateway jar answered `readyz` 200/true with the OLD fail-open
`EXECUTION_ENABLED=false` semantics, hiding until a probe found the halting
defect in the NEW source. Nobody had a machine check for "image older than
source"; the discovery was accidental (manual `docker image inspect` with
`git log`). CHG-101 mechanises that comparison.

## Change

1. **`image_staleness_check.py`** — for every compose service with `build:`:
   source paths = the build Dockerfile's COPY inputs (overlay per service:
   ingestion=parent pom+common+ingestion; execution-bridge=bridge dir+vendored
   SDK; execution-gateway=pom+common+gateway+ingestion per its Dockerfile;
   nautilus=04_executor; ddl-apply/eod-controller=platform corpus+common+SQL
   +scripts+Dockerfile); source epoch = `git log -1 --format=%ct -- <paths>`;
   image epoch = `docker image inspect -f '{{.Created}}' <project>-<service>`;
   STALE when image < source; MISSING when image absent (exit 1); untracked
   sources and uncommitted worktree changes degrade to NO-HISTORY /
   DIRTY-WARN (never silent — printed, exit 0 because the monday gate certifies
   the committed truth; strictness documented in the module docstring).
2. **`make check-image-stale`** — new target; wired into `make gate`
   (run-monday-gates.sh step [8/13], after the docker build smoke) and called
   out as **step 0** of the A2.2 enable checklist.

## Discipline

The overlay source maps mirror the Dockerfiles' COPY statements; a
Dockerfile change that adds/removes a COPY source must update
`SERVICE_SOURCES` (the overlay-consistency unit test asserts every path
exists in the repo, catching typos but not drift — a comment in the module
docstring pins the keep-in-sync contract). Rebuild of all images was the
honest resolution of the guard's own flags (each stale image genuinely
embeds pre-CHG-100 common classes; nautilus is conservative — test-only
parity changes since 16:14 IST do not alter the release binary, but
rebuilding is cheap and clears the flag).
