## Change

1. **Test-count truth re-pin** — a 2026-08-25 live run established ground truth
   (`mvn test` per module + `cargo test --lib`): **common 466 (raw surefire 469
   minus 3 gated `FlussBundleReader*` reports — the C6 gate counts only classes
   present in `src/test`), ingestion 247, compute 387 (plain-suite skip count
   corrected 17→22), Rust lib 196**. The common doc count (466) was already
   correct; the Rust count was understated in the docs (168/164 vs 196), and the
   compute plain-suite skip truth was 17 but is 22. Re-pinned
   `stale_table_kind_scan.py` (`SUITE_TRIPLE_TRUTH` compute skip 17→22; C6
   triple/truth unchanged at 466/247/387 with the gated-report rationale
   recorded), `01-foundation.md` L3 banner (added the 469-raw/466-gated + skip
   corrections), `version_matrix.yaml` (unchanged at 466), Makefile help text
   (`341/236/294` → `466/247/387`), and the stale "576 tests"/"236/340"/"713"
   claims in the dossiers/plan.
2. **Backpressure defaults** — `03-ingestion.md` documented
   `MAX_PENDING_APPEND_RECORDS`=50000 / `MAX_PENDING_APPEND_BYTES`=64 MiB, but
   the code (`AppendTracker`, `IngestionConfig`) defaults are **150000 / 192 MiB**
   (T2 3k-tune). Fixed the 4 config/backpressure lines.
3. **Gate state name** — `05-execution-core.md` said
   `HALTED->RECONCILING->WAITING->ENABLED` and `approve_if_needed`, but
   `gate.rs` implements `HALTED -> RECONCILING -> APPROVAL_PENDING -> ENABLED`
   with `enter_reconciling_if_needed` / `record_approval` / `enable` (bare
   transition to `Enabled` is rejected). Fixed the row.
4. **`SERVICE_HALTED` flag** — docs referenced `SERVICE_HALTED=true` as a code
   default, but the flag does not exist in code. Halt-by-default is enforced by
   `config.rs` rejecting `EXECUTION_ENABLED=true` at boot
   (`execution_enabled=false`, `is_halted_default()`). Fixed the dossier +
   plan references.
5. **Compose container count** — docs said "16 containers / 16 Running";
   `docker-compose.yml` defines **18 services** (3 `execution-t3`
   profile-gated: execution-bridge/gateway/nautilus; 2 one-shot:
   ddl-apply/eod-controller; minio-init exits). Plain `make up` runs **12
   long-running**. Fixed `05-execution-core.md` + `08-local-compose.md`.
6. **CHG-005 DDL status** — CHG-005 removed Ranking/Reservations/Decisions
   from **scope** (requirements/acceptance), but the DDL files
   (`06_ranking_results.sql`, `07_trade_decisions.sql`,
   `15_portfolio_reservations.sql`) were **retained** and still in
   `schema_manifest.json` (applied in the 2026-08-24 scratch run). Annotated
   the docs to say "removed from scope; DDL retained as reserved schema (never
   written by any job)" — no schema change.
