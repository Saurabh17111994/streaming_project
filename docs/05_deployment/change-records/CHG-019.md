## What landed

**M5 — Telemetry + ops + remaining polish (plan §3, §2.3, §2.5, §2.8, §2.9):**
the final hardening milestone. Four test additions plus **one production fix
that the tests drove out**.

| Test | Pins |
| --- | --- |
| `ING-UNIT-021` — `OtlpMetricsEmitterTest.exportBodyScrubsSecrets` | Serializes the full OTLP export body after exercising every recording path with secret-shaped decode-error reasons. **Drove out a real leak (G6):** `appendReasonSum` emitted reason labels verbatim, so a reason like `ARROW_TOKEN=eyJhbGci…` reached the collector. `OtlpMetricsEmitter` now scrubs reason labels with the ING-SEC-RED-001 pattern family (Bearer-then-name=value) and **fails closed** — if any `ARROW_*`/Bearer/raw_payload marker survives the two passes, the whole label collapses to `REDACTED`. |
| `ING-UNIT-022` — `OtlpMetricsEmitterTest.labelCardinalityBounded` | Recursive attribute-key collection across the whole payload pins the exact fixed label set {`service.name`, `service.instance.id`, `slot`, `reason`, `p50`, `p90`, `p99`}; slot label VALUES asserted bounded (`hft-\d+`) — no token/symbol/high-cardinality labels (dossier §Telemetry "bounded-cardinality metrics"). |
| `ING-INT-006` — `test_docker_entrypoint.sh` | Bash harness (shellcheck-clean) for the three `docker-entrypoint.sh` pre-Java FATAL gates: missing `FLUSS_BOOTSTRAP` → exit 2 + message; missing/unreadable manifest → exit 2 + message; missing/non-executable bridge binary → exit 1 + message. Runs the entrypoint under `env -i` so a polluted gate environment cannot mask a FATAL. **Wired into `run-monday-gates.sh`** (new step 4/11) so a contract regression fails the gate. |
| `ING-FAIL-006` — `AppendTrackerTest.warningThrottledToOncePer30sWindow` | The 80% warning listener fires at most once per 30 s window: first crossing fires; re-crossings within the window never re-fire; a 10 s-old marker still throttles; a 31 s-old marker unlocks exactly one re-fire and opens a fresh window. The clock marker is advanced by reflection — no 30 s sleep. |
| `ING-UNIT-020` — `hft_policy_test.go` (G5 remainder) | `TestIngUnit020MissingAppIdAndFatalMessages` (exec-self subprocess): missing `ARROW_APP_ID` → exit 2 + `missing required env: ARROW_APP_ID`; `ARROW_HFT_CONNECTIONS=2` → exit 2 + `FATAL: … pinned to 1`; `ARROW_HFT_LATENCY_MS=49` → exit 2 + `FATAL: … must be in range 50..60000`. The helper env is stripped of policy keys so a polluted test environment cannot mask the FATAL. **G5 fully resolved** (process-level exit codes + message text). |
