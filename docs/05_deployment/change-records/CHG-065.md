## Summary

Closes the B7 gap: the Nautilus service kept its duplicate-send guard
in-process. Four durable clients were designed but flag-gated unbuilt. The
execution service now owns four clients behind dedicated env flags
(`DURABLE_GATE_ENABLED`, `DURABLE_ATTEMPTS_ENABLED`,
`DURABLE_JOURNAL_ENABLED`, `DURABLE_AUDIT_ENABLED`), all default OFF:

- **Gate / Attempts** reuse the existing `GateStateStore` / `AttemptStore`
  traits and `InMemory*` stores (same swap pattern as Workstream D's
  Fluss-backed stores).
- **Journal / Audit** are new append-only traits (`JournalStore` /
  `AuditSink`) with in-memory offline impls; the live slice swaps in
  file/`event_store` and Fluss `Execution_Audit` LOG + OTel behind the same
  traits.

`DurableClients` bundles the four as `Rc`-shared handles so restarts share the
same durable memory (mirrors `ExecutionGate` restart proofs). Flag OFF is
bit-identical to today; enabling any flag in compose requires explicit user
approval recorded in the enabling CHG per B7.5 — default deployment keeps all
OFF until B6 sign-off (DEC-044).
