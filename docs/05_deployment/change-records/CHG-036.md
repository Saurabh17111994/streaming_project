## Summary

DEC-042 records the final execution boundary. Nautilus is the authoritative live execution engine
for order lifecycle, fills, positions, PnL, risk, and broker reconciliation. It runs as a separate
long-lived service. Flink and Fluss provide market-data processing, immutable execution intent,
platform control state, and queryable projections. The localhost go-arrow bridge is the sole
component with Arrow credentials and network access.

This change also reinstates the requirement for a durable execution-intent input. It is distinct
from the retired ranking-era `Trade_Decisions` feed.

## Remaining evidence gates

- Nautilus event-store durability, backup, verification, and seven-year retention evidence.
- Arrow sandbox place/update/fill/reconciliation evidence through the go-arrow bridge.
- Fluss-to-Nautilus intent consumption and Nautilus-to-Fluss projection recovery.
- Gate, fencing, unknown-outcome, restart, and no-duplicate-order tests.
