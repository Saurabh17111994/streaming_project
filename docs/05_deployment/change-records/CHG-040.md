## Summary

This change adds the first offline-safe slice of the separate Go Arrow execution bridge. It pins
the exact vendored SDK tree already used by the market-data bridge, defines a versioned private
command/report boundary, normalizes order-update identities and fills, and provides fake-broker and
race-tested behavior for success, rejection, ambiguity, duplicate request IDs, and reconnectable
postbacks.

The bridge is disabled by default. No Arrow credentials, Rust client, Java gateway, Flink job, live
Compose service, or real order path is added. Arrow sandbox evidence, network isolation evidence,
and production enablement remain outstanding gates.
