## Summary

Turns the `main.rs` stub into a real, fail-closed executable bootstrap: parses strict config,
boots the gate `HALTED`, serves `/healthz` + `/readyz`, and shuts down gracefully on Ctrl-C /
SIGTERM (draining -> `/readyz` 503). This is the "Rust service starts HALTED" piece of WP-1.

## What changed

- **New `src/bootstrap.rs`** — `Runtime::init(config)` builds `Gate` (boots `HALTED`), asserts
  health does not imply `ENABLED`, and holds the shared `ServerState` the health server reads.
  Includes the offline `EngineFactory::verify_construction_path` probe.
- **New `src/http.rs`** — minimal dependency-free `tokio` HTTP/1.1 health server:
  `GET /healthz` (process alive + gate state, never implies trading) and `GET /readyz`
  (200 while running, 503 while draining).
- **`src/main.rs`** — real bootstrap: `ServiceConfig::from_env()` -> `Runtime::init` ->
  serve health -> wait for Ctrl-C/SIGTERM -> `begin_shutdown()` (draining) -> abort server ->
  exit 0.
- **`src/config.rs`** — relaxed to health-only boot: gateway/bridge endpoints are now optional
  (consumed only when connecting later), new `EXECUTOR_LISTEN_ADDR` (default `127.0.0.1:8787`),
  `EXECUTION_ENABLED=true` still fails closed at boot (test), and config **never** reads
  `ARROW_*` (test proves presence of `ARROW_REST_URL`/`ARROW_APP_ID`/`ARROW_TOKEN` changes nothing).
  Refactored parsing body into testable `from_iter()`.
- **`src/lib.rs`** — registered `pub mod bootstrap;` and `pub mod http;`.
- **`Dockerfile`** — no change needed; the existing multi-stage image (rust:1.97.1 ->
  bookworm-slim, `ENV EXECUTION_ENABLED=false`) is now fully sufficient for boot because endpoints
  are optional.

## What did NOT change

- No `LiveNode` / OMS / risk / portfolio wiring (deferred to WP-2).
- No Fluss reader/writer path yet (WP-3).
- The **Docker image build is env-gated and NOT run here** — it needs network for the pinned
  Nautilus git deps + the `rust` base image and a long release compile. Runs in WP-6 Compose / CI.
  Source does compile offline (`cargo build/bin nautilus-execution-service`).
