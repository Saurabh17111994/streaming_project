## Summary

This change completes the offline-safe Signal-side execution-intent producer slice. The producer
derives a deterministic MVP entry trade context, builds the versioned immutable intent row, and
appends it to `Execution_Intent` only when explicitly enabled with an account scope, partition,
product, time-in-force, and configuration version. The default remains disabled, invalid rows
produce no executable output, and durable quarantine remains a Java gateway responsibility for T2.

The Rust toolchain pin is recorded and the bridge image now uses the patch-level Go 1.24.5 tag.
The host currently provides Go 1.26.4, so Go 1.24.5 image execution and Arrow sandbox credentials
remain evidence gates rather than being claimed as complete.
