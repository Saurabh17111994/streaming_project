## Summary

Closes C1 as **plug-and-play**: the ingestion Go bridge was already wired for
multi-connection fan-out (`subscription_plan.go` `MaxHFTConnections=3` with
round-robin sharding, `hft_slot.go` per-slot reconnect, `supervisor.go`
independent loops) but gated by a hard pin `ARROW_HFT_CONNECTIONS=1`. The pin
is lifted to a tunable range `1..3` (default 1):

* `ARROW_HFT_CONNECTIONS=1` (default, Normal plan) → single socket, 1,024 cap,
  bit-identical to today.
* `ARROW_HFT_CONNECTIONS=3` (Premium plan, when broker allows 3 concurrent
  sessions) → 3 sockets, 3,072 cap, full 2,433 manifest with per-slot 512-chunk
  requests, per-slot reconnect isolation.

Default remains 1 — zero behavior change until Premium. On Premium day: set
`ARROW_HFT_CONNECTIONS=3` in `.env` and restart the bridge — no code change.
