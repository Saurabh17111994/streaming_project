## What happened

At user request, the full compute suite was re-run on the current HEAD with the dev Fluss
stack up — including the env-gated live-integration tests that the default suite skips:

1. **Stack bring-up.** The Fluss containers were `Exited (127)` — a pre-existing stale-container
   bind-mount failure on the `fluss-plugins/iceberg/*.jar` file mounts (runc reported "not a
   directory" against containers created before the jars existed as files). `make up` recreated
   the containers; Fluss came up healthy (port 9123 open, `/etc/hosts` aliases present, tables
   and bucket state persisted on the `fluss-data` volume).
2. **Default suite re-run.** `mvn test -f 02_services/02_compute/pom.xml` (no gates): **292 tests /
   0 failures / 17 skipped** — identical to last night's baseline. The 17 skips are the
   env-gated live tests.
3. **Full gated live run.** All 11 gates exported (`SIGNAL_CHAIN_E2E=true`,
   `COMPUTE_INT_TEST_*` = true for SAFETY/SAVEPOINT/SIG_STATE_RESTORE/SIG_FAIL/COMPAT_FLINK/
   DEDUP_ROCKSDB/SIGNAL_KV/FORMING_BAR_REHYDRATE/P6/P42) plus the R2 credentials and
   `CHECKPOINT_DIR` from the gitignored `code/01_platform/01_docker/.env`. The live tests
   executed for the first time on the current topology/JDK → **6 failures/errors**.

## Root causes

**1. Kryo + JDK 17 module-access gap — dominant (4 of the 6).**
The compute pom's surefire `argLine` opens `java.base/java.nio` and `java.base/java.util` but
not `java.base/java.util.concurrent.atomic`. Any live job that serializes Flink's
`BinaryRowData` via Kryo fallback (candle output through the late-drop side-output) crashes with
`InaccessibleObjectException: Unable to make field private volatile int
java.util.concurrent.atomic.AtomicBoolean.value accessible`. The `candle-15s ->
candle-late-drop-counter` operator died with this exact stack in:
- `CandleGraphReplayIntegrationTest.logReplayAndRestoreIdempotency` and
  `dataQualityRejectionsAndWindowSemantics` (jobs `p6-phase1` / `p6-data-quality` stuck at FAILED)
- `CandleFailureInjectionIntegrationTest.checkpointFailureTriggersConfiguredRestartThenFails`
  (job `p63-cp-failing` never reaches RUNNING — same operator crash)

Pre-existing config gap; invisible because these tests are P6-gated and never ran in any
default-suite "green" pass. One-line fix: extend the argLine.

**2. Stale pinned-UID contract (1).**
`SignalJobOperatorUidTest.everyOperatorCarriesPinnedUid`: the graph carries **14** UID'd
operators but `EXPECTED_OPERATORS` pins **10** — "expected: <10> but was: <14>". Drift from the
CHG-023 topology change (StallGuardedSink removal unwrapped the signal-candidates-current and
TradeDecisions sinks), never caught because the test is P6-gated. Savepoint-anchor contract
violation (CHECKPOINT-RESTORE-001) — the pinned set must be reconciled with the 14-operator
graph.

**3. Missing faketool binary (1 error).**
`SignalChainLiveE2ETest.fullChainBrokerToFeatureTable` errors in ~3 s:
`Cannot run program "go-bridge/faketool/faketool": No such file or directory`. The Go source
exists (`code/02_services/01_ingestion/go-bridge/faketool/main.go`, the CHG-023-fixed faketool)
but the binary is a gitignored build artifact and was never built in the main folder (worktree
copies exist; `go 1.26.4` is available). Prerequisite, not a code failure.

**4. Watermark-stall assertion (1, not fully isolated).**
`CandleFailureInjectionIntegrationTest.watermarkStallFreezesOutputAndResumesCleanly`: flat
windows fired 5 signals during the stall window (expected 0). Same class as root cause 1's
crash; plausibly downstream of it, but requires isolation after the Kryo fix.
