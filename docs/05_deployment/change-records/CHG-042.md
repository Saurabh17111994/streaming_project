## Summary

This change adds the Java 17 Fluss Execution Gateway boundary. It provides fail-closed intent
validation, bounded Fluss control reads, an HMAC-authenticated versioned private protocol to the
Nautilus service, explicit projection serializers, a durable projection ledger, and separate
health/readiness dimensions. Java remains a transport/projection adapter: it does not own broker
credentials, Arrow access, order lifecycle arithmetic, or position arithmetic.

The two composite-key KV tables used by the gateway now retain their account-safe composite
primary keys while using the verified Fluss 0.9.1 raw-client-compatible shape: `kv.format-version=2`
with a single-field subset bucket key (`account_scope_id` for `Order_Lifecycle`, `instruction_id`
for `Order_Correlation`). The DDL manifest and agreement tests are regenerated. The live matrix,
scratch append/lookup, and end-to-end Fluss restart evidence are intentionally still open gates.
