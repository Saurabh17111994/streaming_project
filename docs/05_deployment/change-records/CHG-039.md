## Summary

This change records the first offline implementation slice of the Nautilus execution design. It
adds a dedicated append-only `Execution_Intent` contract and pins the audited Nautilus reference
commit without enabling an intent producer, gateway, executor, Arrow bridge, or live order path.
The retired ranking-era `Trade_Decisions` feed remains unchanged and disabled.
