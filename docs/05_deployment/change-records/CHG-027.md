## What landed and why

CHG-026 consolidated the three execution dossiers into `05-execution-core.md` (Nautilus →
go-arrow bridge → Arrow) but deliberately left the authoritative upstream layer on the old
standalone-service wording, recording the re-scope as the implementation gate. This change closes
that gate:

- **Contracts** (`04_contracts/05/06/07`): re-scoped to the Execution Core architecture. The
  go-arrow bridge (localhost, wrapping the pinned `go-arrow` SDK) is the **only** component that
  can reach Arrow — auth, `POST /order/regular`, modify/cancel, order-updates WebSocket, and
  orders/trades/positions reads. Nautilus provides the OMS, position engine, risk engine,
  reconciliation, fill dedup, and event store; the two-person gate, fencing, attempts,
  correlation, quarantine, and projection sinks remain custom glue. The no-third-party-OpenAlgo
  policy (DEC-006) stands — only its direct-REST wording is superseded.
- **Functional requirements** (`02-functional/05/06/07`): re-scoped in place. Every `REQ-EXE-*`,
  `REQ-AC-*`, `REQ-BB-*` header and every `ASM-EXE-*`/`ASM-BB-*` assumption ID is preserved, so
  the acceptance matrix (C8: 13/8/13 requirement counts, 152 AC rows) and the risks register stay
  valid with zero matrix changes.
- **Decisions index**: DEC-006 carries a dated supersession annotation for its order-path wording
  (superseded by DEC-041/CHG-027); DEC-041 records that the upstream re-scope landed.
- **Dossier + index**: `05-execution-core.md` banner/status/Contracts row and open-gates item 1,
  and the `00-start-here.md` readiness row, now reflect the resolved re-scope.

Live money stays BLOCKED; no broker call path changed or was enabled. The remaining gates are the
truth-authority decision (Nautilus event store vs Fluss tables), Arrow-sandbox broker evidence
(place → update stream → fill, reconciliation endpoints, client-ref echo), and the untested
go-arrow SDK order path (bridge `PlaceOrder` smoke tests).
