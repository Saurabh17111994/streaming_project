## What changed

1. **`o2-provision.py` ALERTS catalog** — reconciled against the pinned rule table in
   `docs/06_operations/02-ingestion-alerting.md` (11 rules). Added the 10 missing
   entries (`ING-warn-capacity-90`, `ING-crit-capacity-98`, `ING-crit-reconnect-storm`,
   `ING-crit-stale-feed`, `ING-crit-decode-error-burst`,
   `ING-warn-partial-subscription`, `ING-crit-not-ready`,
   `ING-crit-bridge-disconnected`, `ING-warn-heartbeat-failures`,
   `ING-warn-otlp-collector-unhealthy`) with exact doc thresholds; renamed
   `ING-warn-reconnect-streak-5` → `ING-crit-reconnect-consecutive` (doc pins
   severity Critical; nothing was provisioned yet, so the rename is free).
   Rate-window rules use `increase()` because `bridge.reconnects`,
   `decode.errors`, `heartbeat.failures` are cumulative counters
   (`AGGREGATION_TEMPORALITY_CUMULATIVE` in `OtlpMetricsEmitter`); slot metrics
   are per-slot gauges. Documented approximation: decode-burst evaluates a ~70 s
   window each minute (O2 scheduled granularity; doc pins 100/10 s).

2. **`seed_dashboards.py`** — added `_normalize()`: completes repo dashboard JSONs to
   the full v8 schema O2 v0.91.5 requires (`config.show_legends`,
   `queries[].config.promql_legend`, `layout.i`, fields x/y/z/filter defaults).
   Without it every create 422'd (`missing field show_legends`) — the repo files
   carry a reduced panel shape.

3. **`seed_alerts.py` + `position-state-alerts.json`** — fixed three defects that made
   the seeder dead on v0.91.5: routes moved `/alerts` → `/api/v2/{org}/alerts`
   (v2-before-org); alerts gained `"destinations": ["dev-webhook"]` (400 without);
   position-state streams retargeted to the live Flink series names
   (`flink_taskmanager_job_task_operator_compute_*`; short aliases never existed);
   the break-glass SQL alert converted realtime→scheduled with explicit column
   list (O2 rejects `SELECT *` and realtime+sql).

4. **`docs/06_operations/02-ingestion-alerting.md`** — Notes updated: alerts ARE now
   wired into the local OpenObserve instance (previously stated as not expected).
