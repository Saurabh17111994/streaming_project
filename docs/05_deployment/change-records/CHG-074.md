## Summary

Closes the **offline harness half** of A1: the bridge now survives an expired
Arrow session without operator loops — on `401`/`token_expired` (`broker_auth_failure`)
it calls `AutoLogin` with a fresh TOTP exactly once, retries the broker
command once, and on second `401` or `reauth` error flips to `broker_disabled`
with `/healthz` + `/readyz` → `UP disabled` + `503`. Four fake-clock legs
prove exactly-one-retry and fail-closed.

The **one live re-auth check** (real `ARROW_USER_ID/PASSWORD/TOTP_KEY`
against the sandbox auth endpoint, off-hours) needs credentials and is
deferred — it is a single `AutoLogin` round-trip, not a full order.
