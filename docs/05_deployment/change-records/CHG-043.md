## Summary

This change completes the offline T3 fake-broker and network-policy slice. The pinned Go SDK is
exercised against a local HTTP fixture for place, modify, cancel, query, and reconciliation. A
local WebSocket fixture drives acknowledgement, partial/full fills, cancellation, rejection,
unknown status, duplicate identity, out-of-order delivery, malformed text, close, and reconnect
cases. Timeouts and ambiguous responses remain `UNKNOWN` and no place retry is introduced.

Compose now contains a disabled-by-default `execution-t3` profile. The Go bridge alone joins the
private `arrow-egress` network and the internal `execution-net`; it publishes no host port. A
resolved-Compose checker rejects non-bridge egress, public bridge ports, non-internal execution
traffic, and Arrow order credentials outside the documented ingestion market-data exception.

Real sandbox authentication/re-authentication, dynamic cross-container route probes, and real
broker evidence remain intentionally blocked and are owned by T8/T9.
